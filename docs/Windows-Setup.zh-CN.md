# Windows 安装与使用（v0.3.1）

## 桌面一键打开

完整解压后首次运行启动器，会自动在当前用户桌面创建「王洪文语音工作室」快捷方式；安装成功后也会补建。以后双击桌面图标，程序自动启动本地服务并打开网页，无需再次点击「打开工作室」。重复点击会打开已有实例。首次使用仍需完成安装，单纯下载 ZIP 不会自动执行程序。

请保留完整程序文件夹。移动程序后，运行新位置的 EXE，或在启动器底部点击「创建 / 修复桌面快捷方式」。桌面权限受限时，快捷方式失败不会阻止安装；仍可运行 EXE。使用期间保持启动器开启。

## 1. 准备

64 位 Windows 10/11、6 GB 级或以上 NVIDIA 显卡、可用 NVIDIA 驱动。建议系统内存 16 GB 以上，安装前预留 30 GB 空间。首次安装及首次生成需联网下载数 GB。CPU/AMD/Intel 显卡没有独立兼容模式。

物理 6 GB 显卡尚待实机验证：已完成的是在 16 GB 显卡上限制 PyTorch 分配到 4.5 GiB 的运行测试，见 [验证记录](v0.3.0-Validation.md)。

## 2. 安装

1. 从 [最新发布](https://github.com/2009Wu/wang-hongwen-voice/releases/latest) 下载 **Wang-Hongwen-Voice-Studio-Windows.zip**；不要选 GitHub 自动生成的 Source code 代替新手包。
2. 完整解压到有足够空间的普通文件夹。
3. 双击 **Start Voice Studio.exe**，点击 **安装并打开工作室**。
4. 等待中文进度完成，浏览器自动打开本地页面。

无需管理员权限、Docker、终端命令或系统 Python。程序没有代码签名，请核对来源，不要关闭安全保护。需要重试时点击 **修复安装**；完整下载可复用。

## 3. 一键生成

- **文字语音：** 在「文字 → 生成语音」输入文字，点击「一键生成」。默认中文，最多 600 字。
- **歌曲翻唱：** 放入一个有人声的音频/视频，点击「一键生成」。支持 MP3/WAV/M4A/MP4/FLAC 等，最多 500 MB、10 分钟。纯伴奏不会自动产生歌词。
- 一次只用文字或文件其中一种；两者都有会提示先清除一个。
- 完成后试听，下载 MP3（通用）或 FLAC（无损且通常更小）。「更多下载」内有 WAV、MP4 和参数记录。

生成结果仅临时保留，请及时下载。网页「停止」取消当前任务；启动器「停止」关闭本地服务。使用时保持启动器开启。

## 4. 自动性能与效果

默认自动选择：6 GB 用 CPU 分离伴奏并让生成模型分阶段占用 GPU；8 GB 改用 GPU 分离；12 GB+ 减少模型搬运。判断依据包括当前空闲显存，游戏等程序会影响档位和是否能运行。

高级选项默认收起，可以选择「6 GB 节省显存」解决内存压力。档位不会降低模型精度、参考音频或默认 40 步，也不会改调。默认人声 +4.5 dB、伴奏 −1.5 dB；可自行修改。快速 20 步是用户可选项，不会自动启用。

## 5. 磁盘与无损压缩

安装 ZIP 无损压缩，模型首次使用时下载。成功安装后清理 `.runtime/pip-cache` 和 `.runtime/downloads`，保留私有 Python、字节码、依赖及 `.cache` 模型。修复安装时可能重新下载所需文件。

FLAC 压缩 WAV 的原始 24 位样本，解码后完全一致；文件大小取决于素材。MP3 保持原 320 kbps；没有通过模型量化、裁剪或降低码率节省空间。

## 6. 文件与隐私

`.runtime` 是独立环境与日志，`.cache` 是模型。只监听 127.0.0.1。歌曲和文字由本机处理，不会自动发布到 GitHub/Hugging Face，也不会调用外部推理 API。安装需要下载依赖和模型。

## 7. 更新到新版本

没有自动升级；修复安装不等于升级。先保存生成结果并关闭启动器，下载新 ZIP 完整解压。推荐保留旧目录以便回退。可复制旧 `.cache` 到新目录复用模型，不必复制 `.runtime`；在新位置安装环境。仅移动原目录时点击修复安装刷新路径。

## 8. 常见问题

| 情况 | 处理 |
|---|---|
| 显存不足 | 关闭游戏等 GPU 程序，选 6 GB 节省显存，重试；显卡还需满足最低要求 |
| 没检测到 NVIDIA 显卡 | 更新驱动、重启，点击修复安装 |
| 下载中断 | 检查网络，重试；完成的模型文件会缓存 |
| 首次生成较慢 | 观察进度，可能正在下载或载入模型；低显存档位还会用 CPU |
| 磁盘不足 | 安装前预留 30 GB 空间；不要删除正在使用的环境和模型 |
| 页面未打开 | 查看「打开安装日志」和 `.runtime/app.log`，尝试修复安装 |

## 安装体积 / Disk use

安装与启动时自动清理本程序不使用的 PyTorch 开发静态库和 ffplay 播放器，实测运行环境节省 980,103,826 字节（约 980 MB / 0.91 GiB）。不改模型权重、运行 DLL、精度、步数、音高和混音。保留模型缓存和 Python 缓存。安装时仍需预留 30 GB，首次仍会下载数 GB。

开发者需要编译自定义 C++ 扩展时，请另建完整开发环境；启动器维护的是配音和翻唱所需的推理环境。升级时先保存结果、关闭启动器，把新 ZIP 完整解压覆盖回原位置，可保留 `.runtime` 和 `.cache`；下次打开会自动精简。请勿只复制 EXE。


安装前的 30 GB 可用空间包含下载、解压临时文件，不是装好后长期占用。自选音色装好并缓存全部模型后实测约 11.25 GiB；王洪文主要模型和运行库接近，实际大小随缓存与结果变化。v0.3.3 进一步清理不使用的演示资源、开发头文件和工具文档，保留模型、音质参数和加速缓存。
