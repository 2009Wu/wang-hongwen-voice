## Windows 安装修复

- 修复首次安装在「正在准备音视频工具」时遇到的 FFmpeg 下载 404。
- 下载失败会显示依赖名称和 HTTP 状态。点击「打开安装日志」可查看出错地址。
- 可在下载时点「停止」。失败后可用「修复安装」重试，或点「关闭」。已校验的 Python 和 FFmpeg 安装包可复用。

在 Windows 11 上完整解压 **Wang-Hongwen-Voice-Studio-Windows.zip**，双击 **Start Voice Studio.exe**，选择「安装并打开工作室」。请解压到当前账户有写入权限、且允许程序运行的文件夹。安装器以当前账户运行。校方策略拦截时，请联系学校 IT。

## Windows installer repair

The installer now uses the versioned Gyan mirror for FFmpeg 8.1.2 and checks the same SHA-256. Failed downloads identify the dependency and HTTP status, with the requested URL in the setup log. You can stop a download, close a failed setup, or retry with verified archives still in the cache.
