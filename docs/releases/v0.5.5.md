## 更新时同步桌面图标

- 安装更新自动重启后，缺失的桌面快捷方式会补建。
- 已有同一工作室的快捷方式时沿用它，包括指向当前程序的改名快捷方式。
- 新版包含不同图标时，原快捷方式会更新图标；同一个快捷方式继续使用。

首次安装请完整解压 **Wang-Hongwen-Voice-Studio-Windows.zip**，再运行 **Start Voice Studio.exe**。

## Desktop shortcuts after updates

After an update, the studio restores a missing desktop shortcut, reuses an existing shortcut to the same installation, and refreshes the shortcut in place when the app icon changes.
