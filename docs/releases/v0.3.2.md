## 王洪文语音工作室 v0.3.2

### 本次更新

安装与启动时自动清理本程序不使用的 PyTorch 开发静态库和 ffplay 播放器，实测运行环境节省 980,103,826 字节（约 980 MB / 0.91 GiB）。不改模型权重、运行 DLL、精度、步数、音高和混音。保留模型缓存和 Python 缓存。安装时仍需预留 30 GB，首次仍会下载数 GB。

王洪文 Windows 包从约 4.07 MB 减到约 2.4 MB。参考录音采用无损打包，安装时还原成完全相同的 WAV；不需要用户额外操作。

### 使用

1. 下载附件 **Wang-Hongwen-Voice-Studio-Windows.zip** 并完整解压。
2. 双击 **Start Voice Studio.exe**，首次点击「安装并打开工作室」。
3. 输入文字或上传带原唱的歌曲，点击「一键生成」。

安装后使用桌面图标打开；保持启动器开启。Windows 10/11 64 位、6 GB 级以上 NVIDIA GPU，建议 16 GB 系统内存。首次安装和下载模型需联网。

升级：保存结果并关闭旧程序，将完整新包覆盖回原位置，可保留 `.runtime` 和 `.cache`，下次启动自动精简。请勿只复制 EXE。

### 验证

两个程序均已实际生成中文配音和歌曲翻唱；同一段自选配音精简前后的 WAV 逐字节一致。模型及运行 DLL 校验一致。此次复用已有环境与缓存，没有重复从零安装或完成多轮性能统计；详见 docs/v0.3.2-Storage-Validation.md。

校验值见 ZIP 同名 `.sha256` 附件。软件 GPL-3.0，上游及参考素材许可见项目说明。生成音频是 AI 演绎，并非真实录音。
