## 修复桌面快捷方式

改用 Windows 自带的快捷方式接口，在首次运行和安装完成后检查桌面图标。启动器会显示创建结果；移动工作室目录后可重新运行启动程序修复图标。

下载 ZIP 并完整解压，双击其中的启动程序。首次运行会在当前 Windows 账户的桌面创建可双击打开工作室的图标。 安装包为 **Wang-Hongwen-Voice-Studio-Windows.zip**，启动程序为 **Start Voice Studio.exe**。

## Desktop shortcut

Extract the ZIP and run the launcher from the extracted folder. It creates and verifies the current user's desktop shortcut on first launch and checks it again after setup. The setup window shows the shortcut status and offers repair.
