## Windows 桌面版与一键更新

- 工作室现在有自己的 Windows 窗口，从桌面图标直接打开。关闭窗口会结束后台服务。
- 启动时自动检查更新。有新版时显示右下角提醒和版本说明，点击「安装更新并重启」即可完成升级。
- 简化页脚提示。

### 安装

从本页下载 **Wang-Hongwen-Voice-Studio-Windows.zip**，完整解压后运行 **Start Voice Studio.exe**。首次使用按提示安装。工作室窗口使用 Microsoft WebView2 Runtime。

## Windows desktop app and one-click updates

- Open the studio from its desktop shortcut. Closing the studio stops its local service.
- Available updates show release notes and a notification. Choose **Install update and restart** to upgrade.
- Simplified the footer.

Download the Windows ZIP from Assets and extract it before running the app.
