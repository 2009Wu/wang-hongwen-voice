# v0.4.0 验证记录

环境：Windows 11 / RTX 5070 Ti 16 GB，原有 Python 3.12.10、PyTorch 2.7.1+cu128、Gradio 6.31.0。此次复用现有环境和模型缓存，不是重新下载所有依赖的空缓存安装测试。

- 31 项回归检查分别在音频和界面环境运行，覆盖原有音频/显存/安装清理、输入与旧接口，以及新增作品持久化、收藏、缓存去重、试听裁剪、视频流复用、更新校验与回退。界面环境缺少音频库时，不把导入失败算通过；相关音频检查改在音频环境运行。
- 实际生成：10 秒歌曲试听、沿用试听生成 25.52 秒整首、5–8 秒局部重做、中文文字语音。默认 40 步、原参考、音高与混音参数。两版均输出可解码的 MP3/FLAC/WAV。
- 对 WAV 做样本核对：重做区间以外完全相同；整首中接受的试听片段，扣除约 80 毫秒衔接边缘，样本完全相同；歌曲长度保持 1,125,303 样本 / 44.1 kHz。
- 视频检查：短片段导出时按试听起点裁剪；重做导出复用视频流，逐包 SHA-256 一致。
- 作品持久化：删除任务临时目录、清理可修改素材后，最终导出仍可读取；素材过期后重试提示需要重新上传。成功返回后关闭生成器不会将作品误记为失败。
- 缓存：同盘迁移使用硬链接，内容相同的旧文件去重；部分下载文件与登录令牌不迁移。已安装自选版实际将 174 个模型缓存文件接到默认共享目录，无内容冲突。
- 更新：ZIP SHA-256、清单文件、越界路径、保留目录、重复/Windows 无效文件名和已暂存文件篡改检查；模拟写入失败恢复旧代码、模拟中断记录恢复。更新不会替换模型、私有环境或作品目录。
- 两个原生启动器重新编译并通过参数、中文/空格路径、桌面快捷方式和安装缓存边界自测。自选版实际测试原生更新交接、程序重启、回退及回退后代码哈希和历史文件一致。王洪文版共享相同更新实现，未重新建立常驻安装。
- 自选版额外测试：参考片段提取、收藏、选择、移除回调；安装后的 `/create` 经真实 Gradio 上传与生成，返回永久文件并可下载。原先“永久作品在程序目录以外被下载服务拦截”的问题已修正，只允许作品、收藏、参考预览和诊断目录，不公开私有请求和历史 JSON。

## 界面和边界

新页面已在浏览器实际打开，确认生成、作品历史、更新与帮助及参考/试听控件。浏览器工具随后因无法可靠识别当前窗口网址停止，尚未完成本版所有按钮的逐项人工点击、波形拖动裁剪与移动端布局测试。功能回调和真实 API 检查不能代替这些视觉交互验证。

未重新验证全新公网安装、Linux Docker、物理 6 GB 显卡及所有歌曲/语言。未换用 Vevo、未加入此前撤回的音色实验。模型原有限制仍在：短或嘈杂讲话不能保证演唱相似度，局部重做也不能保证发音更准确。
