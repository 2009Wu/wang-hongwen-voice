# v0.3.1 桌面入口验证

Windows 11 / RTX 5070 Ti 16 GB，2026-11-09。

- 当前用户桌面实际创建中文 .lnk，目标为本程序 EXE，参数 `--open`，工作目录为程序目录。
- 通过 Windows 实际打开桌面 .lnk，未点击启动器的打开按钮，本地界面自动就绪；耗时约 11.0 秒。
- 再次打开同一个桌面入口，复用原启动器 PID，没有另开本地服务。
- 中文含空格路径下创建快捷方式、移动目录后重建目标、参数及工作目录自检通过。
- 原启动器的参数转义、ZIP 路径防越界、选择性安装缓存清理自检通过。
- 本次修改仅涉及启动器、说明和打包；生成引擎、模型、参考音频、混音参数保持原样，之前音频验证仍见原验证记录。

下载 ZIP 本身不会执行程序。用户必须完整解压并首次运行 EXE；未安装环境时仍显示安装按钮。之后使用桌面图标自动启动并打开工作室。移动文件夹后需运行新位置的 EXE 修复入口；当前按程序名称保留一个桌面入口，最后运行的位置成为目标。

本次未重新下载全部依赖，也未验证所有 Windows 桌面重定向/受限权限环境。桌面快捷方式创建失败会显示日志或错误提示，不改变安装成功标记。
